# Software Testing & Quality Ass

This project focuses on setting up a JavaScript testing environment using **Node.js, Git, Jest, Mocha, Chai, Supertest, Cypress, ESLint, and NYC**. It includes verification tests, API testing, unit testing, code coverage, and code quality checks.

## Technologies

* Node.js
* Git & GitHub
* Jest
* Mocha & Chai
* Supertest
* Cypress
* ESLint
* NYC

  

## Getting Started

```bash
npm install
npm test
npm run lint
```

The project follows a structured software testing and quality assurance workflow, including project setup, testing dependencies, configuration, verification tests, coverage analysis, and linting.
